# Git Visual

Git Visual is planned as a graph-first desktop Git client for exploring repository history and inspecting historical files. The app is still in the design stage; history features are not implemented yet.

## Current project documents

- [Initial design v0.6.0](GitVisual-InitialDesign-v0.6.0.md) — product scope, proposed behavior, open decisions, and acceptance criteria.
- [Development workflow v1.2.1](devstatemachine-v1.2.1.md) — reusable workflow governing design, implementation, testing, and acceptance.

Versioned project documents include SemVer in their filenames and matching internal titles. Keep one current file per document type and rename it when the version changes; Git history preserves prior versions. This root `README.md` remains the landing page and project overview because GitHub expects that filename for automatic display.
